Plain-language policy

How CSS Cause Map handles your data

Effective August 28, 2026

CSS Cause Map analyzes the page inside Chrome. We do not run analytics or collect browsing history.

What stays in Chrome

Measurements, CSS selectors, parent evidence, and saved reports remain in browser storage. The demo uses only keys beginning with demo:.

When data leaves Chrome

A report leaves Chrome only when you export and share it. The extension makes no network requests.

Permissions

The extension asks for active-tab, scripting, storage, and side-panel access. It starts only after you choose it on the current tab.

Exports

Reports exclude page text. They remove query strings and URL fragments. You can replace selectors with anonymous labels.

Delete local data

Resetting the demo removes its sample state. Use Clear report log in Saved reports to delete every saved report and private note.
